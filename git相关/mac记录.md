# 从Windows到Mac用户过渡指南

## 快捷键差异

### 基本操作快捷键
- **复制**: Windows: Ctrl+C → Mac: Cmd+C
- **粘贴**: Windows: Ctrl+V → Mac: Cmd+V
- **剪切**: Windows: Ctrl+X → Mac: Cmd+X
- **撤销**: Windows: Ctrl+Z → Mac: Cmd+Z
- **全选**: Windows: Ctrl+A → Mac: Cmd+A
- **保存**: Windows: Ctrl+S → Mac: Cmd+S
- **关闭窗口**: Windows: Alt+F4 → Mac: Cmd+W
- **锁定电脑**: Windows: Win+L → Mac: Control+Shift+Power（或Control+Command+Q锁定屏幕）

### 系统导航快捷键
- **切换应用程序**: Windows: Alt+Tab → Mac: Cmd+Tab
- **截图**: 
  - Windows: PrtScn 或 Alt+PrtScn
  - Mac: Cmd+Shift+3（全屏）或 Cmd+Shift+4（选择区域）
- **打开任务管理器**: Windows: Ctrl+Alt+Del → Mac: Cmd+Option+Esc（强制退出）
- **Spotlight搜索**: Windows: Win+S → Mac: Cmd+Space

## 界面和操作习惯差异

### 文件管理器
- **Windows资源管理器** → **Mac访达(Finder)**
- 路径显示在顶部标题栏
- 侧边栏用于快速访问常用位置
- 标签页功能：Cmd+T新建标签页

### 右键菜单
- Windows: 鼠标右键单击
- Mac: 
  - 触控板双指点击
  - 鼠标右键单击（如果配置了双按键鼠标）
  - Ctrl+单击

### 窗口管理
- **最大化窗口**: Windows: 点击最大化按钮 → Mac: 绿色按钮（单击进入全屏或双击标题栏）
- **最小化窗口**: Windows和Mac都是黄色按钮或Cmd+M
- **关闭窗口**: Windows和Mac都是红色按钮或Cmd+W

## 常用功能替代方案

### 系统设置
- **控制面板/设置** → **系统偏好设置**
- **任务栏** → **Dock栏**
- **开始菜单** → **Launchpad**

### 常用软件替代
- **Microsoft Office** → **iWork套件**（Pages、Numbers、Keynote）
- **记事本** → **TextEdit**
- **画图工具** → **Preview预览**或**Photoshop**
- **WinRAR/7-Zip** → **内置解压缩功能**或**The Unarchiver**

## 开发环境差异

### 终端使用
- **Windows命令提示符/CMD** → **Terminal终端**
- **PowerShell** → **Terminal中的zsh/bash**
- 常用命令差异：
  - 查看目录内容: dir → ls
  - 清屏: cls → clear
  - 创建目录: mkdir dirname → mkdir dirname
  - 删除文件: del filename → rm filename

### 快捷键在开发中的应用
- **VSCode等IDE**中大部分快捷键类似，但Ctrl键变为Cmd键
- **复制行**: Windows: Ctrl+C → Mac: Cmd+C
- **查找**: Windows: Ctrl+F → Mac: Cmd+F
- **替换**: Windows: Ctrl+H → Mac: Cmd+Option+F

## 特殊手势和触控板操作（MacBook）

### 触控板手势
- **单指**: 鼠标移动
- **双指滑动**: 滚动页面
- **双指点击**: 右键菜单
- **三指左右滑动**: 在全屏应用间切换
- **四指上滑**: 显示Mission Control（所有打开的窗口）
- **四指下滑**: 显示Launchpad
- **捏合**: 缩小
- **展开**: 放大

## 常见问题及解决方案

### 输入法和语言切换
- Windows: Alt+Shift 或 Win+Space
- Mac: Cmd+Space（默认）或自定义快捷键

### 安装软件注意事项
- 下载.dmg文件后，需拖拽到Applications文件夹才能安装
- 首次运行新应用可能需要在系统偏好设置→安全性与隐私中允许运行

### 文件路径和命名
- Mac使用Unix风格路径，分隔符为"/"
- 不支持某些特殊字符如"\"、":"等
- 文件名区分大小写敏感度不同

### 网络和共享
- Windows网络邻居 → Mac的AirDrop或手动连接服务器
- SMB共享连接方式略有不同

## 提高效率的小技巧

1. **使用Spotlight搜索** (Cmd+Space) 快速启动应用和查找文件
2. **善用Mission Control** (F3或四指上滑) 管理多个桌面和应用
3. **自定义Dock** 添加常用应用和文件夹
4. **使用Finder标签页** 管理多个文件夹浏览窗口
5. **学习使用brew** 包管理工具安装开发工具
6. **熟悉Touch Bar** (适用于带Touch Bar的MacBook)
7. **使用Alfred等效率工具** 替代Spotlight获得更强功能

## 学习建议

1. 初期可以打印快捷键备忘录贴在显示器旁
2. 尝试逐步将日常工作流程迁移到Mac上
3. 学会使用Mac原生应用的基本功能
4. 加入Mac用户社区获取经验和技巧
5. 保持耐心，适应需要一定时间
