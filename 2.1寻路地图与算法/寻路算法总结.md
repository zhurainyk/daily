## 基础概念

### 栈 vs 队列
- **队列**: push + shift (先进先出)
- **栈**: push + pop (后进先出)

寻路问题适合使用**广度优先算法**(队列),而不是深度优先算法(栈),因为广度优先能保证找到最短路径。

## 广度优先搜索(BFS)

### 算法原理
广度优先搜索像水波扩散一样,从起点开始,逐层向外扩展,保证找到的一定是最短路径。

### 实现步骤
1. 将起点放入队列
2. 从队列中取出一个点
3. 判断是否是终点,如果是则返回
4. 将该点的上下左右邻居加入队列
5. 重复步骤2-4,直到找到终点或队列为空

### 核心代码
```javascript
function path(map, start, end) {
  var queue = [start];  // 队列存储待访问的点
  
  function insert(x, y) {
    // 边界检查
    if (x < 0 || y < 0 || x >= 100 || y >= 100) return;
    // 检查是否是墙或已访问
    if (map[y * 100 + x]) return;
    // 标记为已访问
    map[y * 100 + x] = 2;
    // 加入队列
    queue.push([x, y]);
  }
  
  while (queue.length) {
    let [x, y] = queue.shift();  // 从队列头部取出
    
    // 找到终点
    if (x == end[0] && y == end[1]) {
      return true;
    }
    
    // 扩展四个方向
    insert(x - 1, y);  // 左
    insert(x + 1, y);  // 右
    insert(x, y + 1);  // 下
    insert(x, y - 1);  // 上
  }
  
  return false;  // 无法到达
}
```

### 优缺点
- **优点**: 保证找到最短路径
- **缺点**: 搜索效率较低,会搜索大量无关区域

## 可视化寻路

### 实现逻辑
在BFS的基础上,添加可视化效果:
1. 使用 `sleep()` 函数实现延时
2. 给访问的点上色,展示搜索过程

### 核心代码
```javascript
// 延时函数,用于可视化
function sleep(t) {
  return new Promise(res => {
    setTimeout(res, t);
  });
}

async function insert(x, y) {
```

### 效果
- 红色: 起点
- 蓝色: 终点
- 绿色: 正在搜索的区域
- 紫色: 已访问区域

## 路径绘制

### 实现逻辑
当找到终点后,需要绘制从起点到终点的完整路径。关键点是**记录每个点的前驱节点**。

### 实现步骤
1. 使用 `table` 对象记录每个点的前驱节点
2. 找到终点后,从终点反向回溯到起点
3. 将路径标记为紫色

### 核心代码
```javascript
async function findPath(map, start, end) {
  let table = Object.create(map);  // 记录前驱节点
  
  async function insert(x, y, pre) {
    // ... 边界检查 ...
    
    table[y * 100 + x] = pre;  // 记录前驱节点
    queue.push([x, y]);
  }
  
  // 找到终点后,反向绘制路径
  while (x != start[0] || y != start[1]) {
    [x, y] = table[y * 100 + x];  // 回溯到前驱节点
    await sleep(5);
    container.children[y * 100 + x].style.backgroundColor = "purple";
  }
}
```

### 支持斜向移动
除了上下左右,还支持8个方向的移动(包括斜向):
```javascript
await insert(x - 1, y, [x, y]);      // 左
await insert(x - 1, y - 1, [x, y]);  // 左上
await insert(x + 1, y, [x, y]);      // 右
await insert(x + 1, y + 1, [x, y]);  // 右下
await insert(x, y + 1, [x, y]);      // 下
await insert(x - 1, y + 1, [x, y]);  // 左下
await insert(x, y - 1, [x, y]);      // 上
await insert(x + 1, y - 1, [x, y]);  // 右上
```

## 启发式寻路(A*算法)

### 算法原理
A*算法是BFS的改进版,通过**启发式函数**来指导搜索方向,优先探索更有可能到达终点的点。

### 核心思想
- 使用**优先队列**(Sorted类),每次取出距离终点最近的点
- 距离计算使用勾股定理: `(x1-x2)² + (y1-y2)²`

### 数据结构: Sorted类

Sorted类保证每次 `take()` 都能取出"最小"的元素。

```javascript
class Sorted {
  constructor(data, compare) {
    this.data = data.slice();
    this.compare = compare || ((a, b) => a - b);
  }
  
  take() {
    if (!this.data.length) return;
    
    // 找到最小值
    let min = this.data[0];
    let minIndex = 0;
    const len = this.data.length;
    for (let i = 1; i < len; i++) {
      if (this.compare(this.data[i], min) < 0) {
        min = this.data[i];
        minIndex = i;
      }
    }
    
    // 交换最小值到最后,然后删除(O(1)操作)
    this.data[minIndex] = this.data[len - 1];
    this.data.pop();
    return min;
  }
  
  give(v) {
    this.data.push(v);
  }
  
  length() {
    return this.data.length;
  }
}
```

### 完整的A*实现

```javascript
async function findPath(map, start, end) {
  // 距离函数: 计算点到终点的距离平方
  function distance(point) {
    return (point[0] - end[0]) ** 2 + (point[1] - end[1]) ** 2;
  }
  
  // 使用优先队列,按距离终点的距离排序
  let queue = new Sorted([start], (a, b) => distance(a) - distance(b));
  let table = Object.create(map);
  
  async function insert(x, y, pre) {
    // ... 边界检查 ...
    
    table[y * 100 + x] = pre;
    await sleep(0);
    container.children[y * 100 + x].style.backgroundColor = "lightgreen";
    queue.give([x, y]);  // 加入优先队列
  }
  
  while (queue.length()) {
    let [x, y] = queue.take();  // 取出距离终点最近的点
    
    if (x == end[0] && y == end[1]) {
      // 找到终点,绘制路径
      while (x != start[0] || y != start[1]) {
        [x, y] = table[y * 100 + x];
        await sleep(5);
        container.children[y * 100 + x].style.backgroundColor = "purple";
      }
      return true;
    }
    
    // 扩展8个方向
    await insert(x - 1, y, [x, y]);
    // ... 其他7个方向 ...
  }
  
  return false;
}
```

### A*算法特点

| 特性 | 说明 |
|------|------|
| **优先级** | 每次探索距离终点最近的点 |
| **效率** | 比BFS快很多,减少无效搜索 |
| **保证最优** | 能找到最短路径 |
| **适用场景** | 大地图、复杂地形 |

### A vs A*

- **A算法**: 启发式搜索,但可能找不到终点
- **A*算法**: A算法的特例,保证能找到终点且是最优路径

---

## 算法对比

| 算法 | 数据结构 | 时间复杂度 | 空间复杂度 | 最短路径 | 适用场景 |
|------|----------|------------|------------|----------|----------|
| BFS | 队列 | O(b^d) | O(b^d) | ✓ | 小地图,要求最优 |
| A* | 优先队列 | O(b^d) | O(b^d) | ✓ | 大地图,复杂地形 |

*注: b是分支因子,d是深度*

## 总结

1. **地图表示**: 使用二维数组,`y*100+x`作为索引
2. **BFS**: 使用队列,保证最短路径,但效率低
3. **可视化**: 添加sleep函数,展示搜索过程
4. **路径绘制**: 记录前驱节点,反向回溯
5. **A*算法**: 使用优先队列+启发式函数,效率大幅提升

### 核心数据结构

- **数组**: 表示地图
- **队列**: BFS的数据结构
- **优先队列(Sorted)**: A*算法的数据结构
- **前驱节点表**: 记录路径信息

### 代码实现要点

1. 边界检查(`x < 0 || x >= 100`)
2. 防止重复访问(`if (map[y*100+x]) return`)
3. 异步处理(`async/await`)
4. 优雅的删除策略(交换后pop,而不是splice)
